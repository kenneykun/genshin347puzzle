崩坏把每个位置写成「律者」——一条法则的垄断；提瓦特把它写成「职位」——一条法则的制衡。

从哪开始？

先点 01 天理 → 02 空 → 10 配，这是一条遮蔽线；再点 13 人，看她在四影与七元素之间的界间轨道。

读法：4 影在上，7 元素在下，01 天理在中间做界面 / 光源；七元素是 6 个固定交点 + 1 个随闪耀窗口移动的雷色，三环中心留空。四影仍是 11→03、10→09、12→08、14→04 四条竖直对应线（03 雷只在闪耀时出现，位置随窗口移动）；02 空固定在 01–10 的遮蔽线上，13 人在四影 / 七元素之间的界间轨道。空之执政的新主人 = 双子（空）按剧情读法处理。这是结构模型，不是官方身份表。

01 / Number skeleton

先把数字拆开。

同一个 14，可以沿四条轴切开：7+7（影侧七 / 光侧七）、11+1+2（7 光 + 4 影 = 11 方向，加 1 理与 2 双子）、12+2（系统与变量）、3+4→7（世界式的折叠）。注意：3 与 4 先折成 7，再与另一个 7 相加；这不是三个互不相干集合的简单加法，而是同一个 7 的隐藏态与可见态。

01 / TWO HEPTADS
14 = 7 + 7

影侧七：4 影 + 2 双子 + 1 天理 = 7；光侧七：7 元素（6 固定 + 1 移动）= 7。天理在光与影之间，不属于任何一侧，但计入影侧的“隐藏七”。影侧七是「谁在写规则」，光侧七是「规则如何显形」；两个 7 是同一个数字的两种状态。

02 / LIGHT + SHADOW + AXIS
11 + 1 + 2 = 14

7 光 + 4 影 = 11 个方向；加 1 天理（界面 / 光源）与 2 双子，才是 14。它也等价于 12 + 2：1 天理 + 4 影 + 7 元素 = 12，双子是两个外部变量。崩坏侧前 12 席在循环内，第 13「人」与第 14「终焉」是能改写循环的一对。

03 / THE WORLD-FORMULA
3 + 4 = 7

世界式的文本把 3 称为表征、4 称为本质，二者叠合为 7，指向一条「垂直超越」的路径。三月、四影、七神是这条式的三个刻度；在本模型里，3 = 天理 + 双子，4 = 四影，7 = 七元素。3 与 4 先折成隐藏的 7，再与可见的 7 相加，才是 14。

04 / THE FOLD
1 + 2 + 4 = 7

节点数是 1、2、4、7。但 2 不占一层：它是两个界间节点。主层是 4-1-7（影 / 理 / 光），1 + 2 + 4 = 7 仍然成立，但 2 是插入项；02 空插在 01 理–10 配之间，13 人插在四影与七元素之间。

02 / From flat tree to solid tree

平面是接线图，
立体是治理树。

世界式的文本原型是卡巴拉生命之树：10 个质点、22 条路径，路径编号 0-21。平面图负责「谁和谁相连」；把它折成 4-1-7 主层 + 2 个界间节点，才能同时读出 (3+4)→7 与 12+2。

平面原型Tree of Life / 10 + 22

路径 18 / 20 / 21 被标成金色：它们正是汇入「王国」的三条下降路径（18 月亮、20 审判、21 世界）。游戏文本出现过「第18、世界和20的路径」的说法；「世界」就是第 21 路径。

数字叠合3 · 4 · 7

三颗内点、四颗中点、七颗外点。世界式的「3+4=7」不是算术题，而是折叠：隐藏的三与四，折进可见的七。

为什么是立体The fold

平面只能画「连接」，立体才能画「层级」。

生命之树的平面图有 10 个质点 + 22 条路径。它很完整，却读不出「影在上、理在中、光在下」的垂直关系。把影层、界面、光层沿纵轴拉开，就得到一棵 4-1-7 的立体树；02 空与 13 人不再占层，而是分别插在 1–4 与 4–7 之间。

这一步是重排，不是篡改：数字仍然是 3、4、7，只是把「路径的接线」折成「层的包含」。折完之后，14 个治理节点同时满足 7+7 与 12+2，也满足 11+1+2。

4 影（上）→ 1 理（界面）→ 7 光（下）
11 + 1 + 2 = 147 光 + 4 影 = 11 个方向；天理在光与影之间，双子是两个界间变量。

主图里上下两个锥体就是这条关系的可视化：上面是影锥（4 影），下面是光锥（7 元素），01 在锥腰，周围一圈七色是棱镜/界面。7 元素的光穿过这层界面，投影成上方的 4 影；11 = 7 光 + 4 影 个方向从这里展开。

四影层不再收成四边形，而是被拉成 四条竖直对应线：11 约束 / 死 → 03 雷 走中线（雷不占固定座位，窗口扫到哪个交点，03 就临时落到哪里），10 支配 / 空 → 09 岩、12 侵蚀 / 生 → 08 草、14 终焉 / 时 → 04 风 各自垂直落到元素。四影仍是四席，几何上却变成一根中轴 + 三根立柱（10 / 12 / 14）。

七元素层现在是 6 个固定交点 + 1 个移动的雷色：六个交点（冰 / 水 / 火 / 草 / 风 / 岩）每隔 60° 一个，三环中心留空；雷没有座位，只在闪耀窗口扫到某个交点时临时出现。图中循环取六点顺序 冰 → 草 → 水 → 风 → 火 → 岩，雷由窗口插入。

在游戏文本里，世界式并不是一张公开的 3D 模型；它是一个可计算的式。所以这张立体图是「读法」，不是「官方截图」。

03 / Light, shadow, prism

十一向轮，三重分光。

如果七元素是光、四影是影，天理就不该躲在影的背面，而应站在光与影之间，做那个界面 / 光源。11 = 7 光 + 4 影；再加 1 理与 2 双子，才是 14。

十一向轮11 = 7 LIGHT + 4 SHADOW

轮上的 11 个方向不是 11 个神，而是 7 个光位 + 4 个影位。中心是 01 天理；两个双子不占轮上的方向，所以 11 + 1 + 2 = 14。

一日食 / 三光栅1 → 3 → 6 + 1

天理是一盏被日食遮挡的点光源，直射光到不了盘心；三面弧面光栅在阴影外接光，把七色反射衍射到底色盘。所以中心留空——显形的七个点里，六个是固定交点，第七个是窗口扫过时才亮起的雷色。

实现选择HTML / Canvas / Three.js

结构图用纯 HTML 就够；真实折射才需要 WebGL。

主图继续用纯 canvas/HTML：可交互、单文件、离线，旋转和节点选择都不依赖外部库。日食与光栅用风格化 SVG 画"光路示意"，不冒充真实光学。

Three.js 本身不负责“分光”；它只是渲染器。要真实色散，需要光谱 + 衍射 shader，甚至光线追迹。对一张结构图来说，成本和可读性都不划算。

如果你要一个能真实旋转、可调光栅角度的光栅实验，可以打开单独的 Three.js / WebGL 页面；但不建议把它塞进当前这个“世界式结构图”里。

05 / The underlying principle

同一部宪法，两种政体。

如果只看「谁像谁」，这张表很快就会变成拉郎配。更有解释力的读法是：14 个位置是不变量，名字是局部变量。崩坏与提瓦特各自把同一组位置写成了不同的制度。

01

数字是不变量，身份不是。

14 个律者是崩坏侧的固定 cycle；提瓦特的 1+4+7+2 也恰好是 14。两边真正共享的不是角色，而是位置的数目与分层。所以本文用「对应」而不是「同一人」：同一条法则，在两个世界里被写成了不同的角色。

02

12 + 2：系统与变量。

提瓦特的行政栈是 12：1 天理 + 4 影 + 7 元素。双子是两个外部变量，所以总数才是 14。崩坏侧的前 12 席在循环内，第 13「人」与第 14「终焉」是能改写循环的一对。一个封闭系统，必须留两个外部位，公式才是可解的。

03

3 + 4 = 7：隐藏的治理折进可见的元素。

世界式说 3 是表征、4 是本质，二者叠合为 7。放在提瓦特：3 是来源（天理 + 双子），4 是四影，7 是七元素。放在生命之树：3 是 veil、4 是 world、7 是 lower sephirot。可见的七，是隐藏的三与四的投影。

04

7 + 7：自然律与概念律。

崩坏侧的 14 可以分成两重七：3-9 的七个自然/元素型律者（雷、风、冰、死、炎、识、地），与1、2、10-14 的七个概念/文明型律者（理、空、支配、约束、侵蚀、人、终焉）。前七管「规则如何成立」，后七管「世界如何显形」。

05

同一权能，两种极性。

崩坏把原理写成「律者」——一条法则的垄断，所以它总是以灾厄出现；提瓦特把原理写成「职位」——一条法则的制衡，所以它表现为神权与执政。空间 ↔ 支配、死亡 ↔ 约束、生命 ↔ 侵蚀、时间 ↔ 终焉：四影是「在任」，四律者是「失控」。同一枚硬币，一面是制度，一面是灾难。

Fan synthesis / 本文的推论

  • 7+4+2+1：把提瓦特读成「七元素 + 四影 + 双子 + 天理」，再与 14 律者对齐。这是结构映射，不是官方名单。
  • 3 = 2+1：把「三月」读成「天理 + 双子」的来源三。官方没有明说这个等式；它来自 3+4=7 与 1+2+4=7 的数字闭合。
  • 10-14 与四影：支配→空、约束→死、侵蚀→生、终焉→时。四影的职名是官方；与具体律者的配对是语义映射，可重排。
  • 四影—元素直线：11 约束 / 死 → 03 雷、10 支配 / 空 → 09 岩、12 侵蚀 / 生 → 08 草、14 终焉 / 时 → 04 风。四影被拉成一中轴 + 三立柱；这是按参考图的直线关系做的重排，不是官方配对。
  • 双子位置：02 空固定在 01 理–10 配的遮蔽线上（按「空之执政已有新主人 = 双子空」的剧情读法）；13 人不占四影层，而在四影与七元素之间的界间轨道上旅行。两者都不再组成「2 双子」几何层。
  • 光 / 影 / 三月分光：把 7 元素读成光、4 影读成影、01 天理读成两者之间的界面 / 光源；11 = 7 光 + 4 影。天理被日食遮挡、三面弧面光栅在阴影外接光，是对七元素"六固定 + 一移动"的结构隐喻，不是游戏内物理。
  • 4-1-7 立体树 + 2 个界间节点：把平面的 10 质点 + 22 路径折成 4 影（上）/ 1 天理（界面）/ 7 元素（光，下）的主层；02 空插在 01–10 的遮蔽线上，13 人插在四影与七元素之间的界间轨道。游戏内的世界式没有公开的 3D 模型；这是本文为了同时读出 (3+4)→7 与 11+1+2 而做的可视化。
  • 「18 / 世界 / 20」：按传统 Tarot 路径编号，18=月亮、20=审判、21=世界；三条都汇入 Malkuth（王国）。游戏文本的并置方式与这套编号吻合，但具体指涉仍以官方文本为准。

What this model does not claim / 它不主张什么

不主张身份同一。天理不是理之律者，荧不是人之律者，Asmoday 不是支配之律者。它主张的是「位置同构」：同一组 14 个功能位，在两个叙事里被赋予了不同的名字与极性。

不主张唯一解。6 死→水 是弱映射；10-12 与四影的配对可以重排；三月=天理+双子 是推论；四影—元素直线（11→03、10→09、12→08、14→04）、02 空的 01–10 遮蔽线、13 人的界间位置、7 光 / 4 影 / 1 界面与三月分光，也都是按剧情、图像与光学隐喻做的结构读法，不是官方关系或官方物理。任何一张 14 对应表都会在这些位置上有争议，本文把争议点直接标出来，而不是藏起来。

不主张官方 3D 模型。世界式是文本与计算式；「4-1-7 立体树 + 2 个界间节点」是读者为了看清数字关系而做的重构。它的价值在于可读、可旋转、可反驳，而不在于「这就是米哈游的原图」。
