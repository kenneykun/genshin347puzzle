# 三光 · 世界式

> 两死，一生。紫越亮，雷眼越暗。

**线上站：[kenneykun.github.io/genshin347puzzle](https://kenneykun.github.io/genshin347puzzle/)**

一套从三环几何、十四席计数和雷神之眼停发现象反推的视觉猜想。不是官方设定。

![站点预览](docs/world_formula_live_preview.png)

## 公式

```text
7 光 + 4 影 + 2 界间 + 1 天理 = 14
7 + 4 = 11
11 + 1 + 2 = 14
```

- **7 光**：冰、水、火、草、风、岩、雷。
- **4 影**：死、生、时、空。
- **2 界间**：`02 空`、`13 人`。双子不是一层。
- **1 天理**：`01 理`。它在光与影之间，不在影的后面。

这套十四席也用来对照《崩坏》侧的十四位律者；逐席对应是解释性的，不是官方名单。

四影在上，七光在下，天理在接触面。双子横跨界面：`02 空` 在 `01 理 – 10 配` 的轴线上，`13 人` 在四影与七光之间的轨道上。

## 核心猜想

1. **14 不是 7+7，而是 7+4+2+1。** 七元素、四影、双子和天理分属不同层级。
2. **七元素由六个环交点加一个暗心组成。** 冰、水、火、草、风、岩都在三环交点上；雷在中心，不在任何环上。
3. **雷神之眼停发，是第七个光位不再被借出。** 其他六元素有自己的交点，雷没有；中心一闭，只有雷断供。
4. **紫不是深渊本身，是深渊的侵蚀。** 紫色在活着的环上，不在雷的暗心上；`紫越亮，雷眼越暗`。
5. **反主不能坐雷位。** 他只能占 `02 空` 或 `13 人` 的界间位，卡住光路、遮住界面，但不能把自己变成雷。
6. **天理在光与影之间。** 不是把天理放到影的背后，而是让 `01` 成为四影与七光的接触面。
7. **中心不能靠叠亮变紫。** 三个环朝向中心的颜色都是 G>B；亮度不能把 B/G 推过 1。中心是洞，不是灯。

## 三环解

三环是一组严格的等圆构造：

```text
外三角半径 R = 7
内三角半径 r = 3.5
环半径 ρ = √(R² − Rr + r²)
         = √36.75
         ≈ 6.0622
```

三个环心落在内三角节点上：

- A：风 `(3.03, −1.75)`
- B：岩 `(0, 3.5)`
- C：草 `(−3.03, −1.75)`

三圆两两相交，六个交点正好是六个元素：

```text
A ∩ B：冰、草
B ∩ C：水、风
C ∩ A：火、岩
```

草、风、岩同时是另一个环的圆心；雷是第七个点，位于三环围出的中心暗区，不在任何环上。

颜色角度（世界坐标，从 x 轴逆时针）：

```text
冰：A60 / B0        水：B180 / C120
火：A240 / C300     草：A180 / B240
风：B300 / C0       岩：A120 / C60
雷：中心，不在环上
```

每个交点上的两个环必须同色。环 C 是活着的月亮，额外加入紫谱；水仍在 120° 保持水蓝。

> 展示版为了构图，把 `09 岩` 放在约 `r = 3.9`；严格三环解是 `r = 3.5`，差 0.4，但拓扑不变。

## 雷眼为什么停发

### 雷没有自己的交点

六个交点产生六个元素；雷是第七个，却是中心，不是交点。  
所以雷的光是从环系统里借来的，不是自己发的。

当中心闭合，或者界面被卡住，只有雷会断供。这就是“为什么偏偏是雷”的结构性回答。

### 三种读法

| 读法 | 结构判断 |
|---|---|
| 雷这个暗点没光了 | 最接近；但更准确是“本来就没有独立光源” |
| 被深渊遮蔽了 | 不准确；深渊在暗心的内侧，不是外侧幕布 |
| 雷位被反主占据了 | 不成立；人和元素是两类节点 |

### 紫与暗心

- 紫在活环上；
- 雷心仍然是黑的；
- 如果雷被深渊从外面盖住，中心应该更紫；但结构里中心反而更黑。

所以更自洽的读法是：

```text
紫 = 深渊之蚀
雷眼 = 深渊闭上的瞳孔
紫越亮，雷眼越暗
```

深渊不是一块布，而是暗心的内侧。雷不是被遮住，而是“闭眼”。

### 反主只能卡界面

`13 人` 可以挡光，`02 空` 可以堵住中心通道；但占雷位会让人和光重复计数，`7+4+2+1=14` 就破了。

反主能做的是关闸、遮光、卡界面，不是变成雷。

### 停发与收缴

- **停发**：没有新的第七光被借出；
- **收缴**：把已经存在的雷光收走（眼狩令）；
- **遮蔽**：界面被占，光路被卡；
- **替代**：结构不允许。

一句话：

> 不是雷元素消失，而是第七个光位不再被允许出现。

## 四影与双子

| 四影 | 对应元素 | 读法 |
|---|---|---|
| 死 / 约 | 雷 | 死亡与契约，落在雷的暗心 |
| 空 / 配 | 岩 / 地 | 空间与配位，落在稳定的大地 |
| 生 / 识 | 草 | 生命与意识，落在草的生长 |
| 时 | 风 | 时间与流动，落在风 |

`10 空` 是四影里的空之执政；`02 空` 是双子里的空。两者不是同一个节点。

双子不是第三层，也不是七光之一。它们可以移动、可以挡路，但不能改变 `7+4+2+1` 的计数。

## 光锥与紫色

左侧 Three.js 场景是“三光源 + 玻璃锥 + 三圈色散”：

- 两圈低亮度：死月；
- 一圈高亮度并带紫谱：活月；
- 中心保持暗。

一个计算上的发现：

```text
朝向中心的 A/B/C 颜色都满足 G > B
加权后的 B/G 大约在 0.27 – 0.80
亮度只能整体放大，不能把 B/G 推过 1
```

所以中心不能靠“把三圈调亮”变成紫色；紫色必须来自额外紫谱，或者来自暗心本身。

## 尚待验证

这套模型仍需要对《空月之歌》的三月模型进行进一步验证。

三月的身份、明暗机制、深渊侵蚀与雷眼停发之间的因果关系，目前是从几何和叙事现象反推的，不足以证明它就是《空月之歌》所呈现的三月结构的正确解释。后续需要结合《空月之歌》的文本与设定逐项核对。

## 边界

- 几何事实：三环半径、六个交点、雷在中心、`7+4+2+1=14` 的计数。
- 叙事推测：四影与元素的对应、雷眼停发的机制、反主与界面的关系。
- 可证伪：
  - 如果雷眼在中心全黑时继续发放，雷眼就不依赖中心；
  - 如果反主被确认坐在雷位，“人和元素分离”不成立；
  - 如果雷神重新发放雷眼而中心不变，“中心闭合”不是充分条件。

结构不是 canon。它只是把“为什么偏偏是雷”“为什么紫在活环”“为什么反主只能卡界面”放进同一张能自洽的图里。
