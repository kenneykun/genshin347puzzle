# 三光 · 世界式

> 两死，一生。紫越亮，雷眼越暗。

**线上站：[kenneykun.github.io/genshin347puzzle](https://kenneykun.github.io/genshin347puzzle/)**

这是一个把《原神》的世界式、三月亮的明暗关系，以及 14 席结构放进同一张图里的视觉猜想站。左边是 Three.js 光锥，右边是 HTML/canvas 的十四节点立体图，中间用 `7 + 4 + 2 + 1 = 14` 串起来。

这套 14 席也用来对照《崩坏》侧的 14 位律者：7 光、4 影、2 界间、1 天理。律者与元素的逐席对应是解释性的，不是官方名单；结构上真正固定的是 `7+4+2+1` 的计数和层级关系。

**这不是官方设定。** 它是一套从视觉结构反推的“可自洽解释”，不是对 canon 的宣称；哪些是几何事实、哪些是叙事推测，下面会分开写。

## 一句话

```text
7 光 + 4 影 + 2 界间 + 1 天理 = 14
7 + 4 = 11
11 + 1 + 2 = 14
```

- **7 光**：七个元素。六个是三环的交点，第七个“雷”是三环围出的暗心。
- **4 影**：死、生、时、空四个执政层。
- **2 界间**：双子。不是一层，是两个可以移动的界间位。
- **1 天理**：`01 理`，在光与影之间，不在影的后面。
- **11**：4 影 + 7 光，构成世界式的十一向骨架。

---

## 核心猜想

1. **14 不是 7+7，而是 7+4+2+1。**
   七元素不是孤立的一层；四影、双子和天理各自占不同的结构位置。

2. **七元素 = 六个环交点 + 一个暗心。**
   冰、水、火、草、风、岩都在三环的交点上；雷在中心，不在任何环上。雷是唯一没有“自己的交点”的元素。

3. **雷神之眼停发，不是雷这盏灯灭了，而是第七个光位不再被借出。**
   六个交点继续发光；中心一旦闭合，依赖中心的雷就断供。这个结构天然解释了“为什么偏偏是雷”。

4. **紫不是深渊本身，是深渊的侵蚀。**
   紫色出现在“活着的环”上，不在雷的暗心上。`紫越亮，雷眼越暗`：深渊侵蚀越强，中心越闭。

5. **反主不能坐雷位。**
   反主是双子之一，只能占 `02 空` 或 `13 人` 的界间位；他能卡住光路、遮住界面，但不能把自己变成雷。若真坐进暗心，他就不是人，而是深渊本身。

6. **天理在光与影之间。**
   4 影在上，7 光在下，`01 理` 在两者的界面上。天理不是“影背后的 boss”，而是光与影交界的那个点。

7. **中心不能靠叠亮变紫。**
   三环朝向中心的颜色都是 G>B；无论怎么加亮度，B/G 都不会超过 1。紫色只能来自额外加入的紫谱，或者来自暗心本身。中心是“洞”，不是“灯”。

## 一、14 席结构

| 层 | 数量 | 角色 |
|---|---:|---|
| 四影 | 4 | 死、生、时、空；世界式的四个执政面 |
| 天理 | 1 | `01 理`；光与影的界面 |
| 七光 | 7 | 冰、水、火、草、风、岩、雷 |
| 界间 | 2 | `02 空` 与 `13 人`；双子，不是一层 |
| **合计** | **14** | `7 + 4 + 2 + 1 = 14` |

四影在上，七光在下，天理在中间：

```text
        4 影
   死 / 生 / 时 / 空
          │
       01 理
          │
        7 光
  冰 水 火 草 风 岩
        + 雷（暗心）
```

双子横跨界面，而不是叠成第三层：

- `02 空`：在 `01 理 – 10 配` 的轴线上；
- `13 人`：在 4 影与 7 光之间的轨道上运行。

这就是“天理在光与影之间”的具体位置：不是把天理放到影的后面，而是让 `01` 成为 4 与 7 的接触面。

## 二、七元素三环解

三环不是随手画的。它是一组严格的等圆构造：

```text
外三角半径 R = 7
内三角半径 r = 3.5
环半径 ρ = √(R² − Rr + r²)
         = √(49 − 24.5 + 12.25)
         = √36.75
         ≈ 6.0622
```

三个环的圆心，正好落在内三角的三个节点上：

| 环 | 圆心 | 角色 |
|---|---|---|
| A | 风 `(3.03, −1.75)` | 风环 |
| B | 岩 `(0, 3.5)` | 岩环 |
| C | 草 `(−3.03, −1.75)` | 草环 |

三圆两两相交，得到六个交点：

```text
A ∩ B：冰、草
B ∩ C：水、风
C ∩ A：火、岩
```

所以六个元素都是交点；而草、风、岩同时又是另一个环的圆心，看起来像“内三角”，其实仍是交点。

**雷是第七个点，位于三个环围出的中心暗区，不在任何环上。**

这就是雷的结构特殊性：

- 其他六元素有交点，有自己的边界；
- 雷只有“内部”，没有自己的边界；
- 雷的光是从环系统借来的，不是自己发的。

## 三、颜色与角度

每个交点由两个环共同定义。按世界坐标角度（从 x 轴逆时针）取色：

| 交点 | 环 A | 环 B | 环 C |
|---|---|---|---|
| 冰 | 60° | 0° | — |
| 水 | — | 180° | 120° |
| 火 | 240° | — | 300° |
| 草 | 180° | 240° | — |
| 风 | — | 300° | 0° |
| 岩 | 120° | — | 60° |
| 雷 | 中心，不在环上 | | |

两条规则：

1. 每个交点上的两个环必须同色；这是“对应”成立的最低条件。
2. 环 C 是“活着的月亮”，额外加入紫谱；但水仍在 120° 保持水蓝，不被紫色污染。

一个容易犯的渲染错误：Canvas 的 y 轴向下，世界 z 轴向上，屏幕角度是世界角度的镜像。若直接拿屏幕角度取色，水会从 120° 的蓝被采成 240° 的紫。正确关系是：

```text
θ_world = 360° − θ_screen
```

## 四、雷神之眼为什么停发

这是整套结构里最强的一个推论。

### 4.1 雷没有自己的交点

六个环交点产生六个元素；雷是第七个，但它是中心，不是交点。

所以雷的“发放”不是从自己的边界发光，而是从整个环系统里 **借光**。

- 六元素：有交点，供光稳定；
- 雷：没有交点，只能借中心的光。

当中心闭合，或界面被卡住，只有雷会断供。  
这就是“为什么偏偏是雷神之眼停发”的结构性回答。

### 4.2 三种常见读法

| 读法 | 结构判断 |
|---|---|
| 雷这个暗点没光了 | 最接近，但更准确是“它本来就没有独立光源” |
| 被深渊遮蔽了 | 不完全对。深渊在暗心的内侧，不是外侧幕布 |
| 雷位被反主占据了 | 结构上不成立。人和元素是两类节点 |

### 4.3 深渊不是盖住雷，是雷的瞳孔

- 紫色出现在“活着的环”上；
- 雷的中心仍然是黑的；
- 如果雷被深渊从外面盖住，中心应该更紫；但结构里中心反而更黑。

所以更自洽的读法是：

```text
紫 = 深渊之蚀
雷眼 = 深渊闭上的瞳孔
紫越亮，雷眼越暗
```

深渊不是一块布，而是暗心的内侧。  
雷不是被遮住，而是“闭眼”。

### 4.4 反主只能卡界面

这里的“反主”，指双子中站在深渊一侧的那一位；“雷眼”是雷元素神之眼的简称。

`13 人` 在 4 影与 7 光之间的轨道上；`02 空` 在 `01 理 – 10 配` 的轴线上。

- 占 `13 人`：站在光圈外缘，可以挡光；
- 占 `02 空`：站在世界式轴线上，可以堵住中心通道；
- 占雷位：会让人和光重复计数，`7+4+2+1=14` 直接破裂。

反主能做的，是“关闸”“遮光”“卡住界面”，不是“变成雷”。

### 4.5 停发与收缴要分开

- **停发**：没有新的第七光被借出；
- **收缴**：把已经存在的雷光收走（眼狩令）；
- **遮蔽**：界面被占，光路被卡；
- **替代**：结构不允许。

所以“雷神之眼停发”最准确的表述是：

> 不是雷元素消失，而是第七个光位不再被允许出现。

## 五、两死一生，与紫的位置

视觉上，三圈色散就是三月亮的隐喻：

- 两个低亮度环：已经死去的月亮；
- 一个高亮度环：活着的月亮；
- 活环加入紫 / 品红谱：深渊侵蚀；
- 中心雷：仍然是黑的。

关键不是“紫色好看”，而是紫色放在哪里：

- **紫在活环上**：深渊在侵蚀“还活着的世界”；
- **雷在暗心上**：雷不是被染紫，而是被留黑；
- **中心不紫**：深渊不是颜色，是缺口。

这也解释了页面文案为什么从“紫 = 深渊”改成：

```text
紫 = 深渊之蚀
紫越亮，雷眼越暗
雷眼 · 闭上的瞳孔
```

## 六、四影、天理、双子的对应

四影不是四个普通元素，而是四个执政面。它们与七元素的对应，是这套猜想里最“解释性”的部分：

| 四影 | 对应元素 | 读法 |
|---|---|---|
| 死 / 约 | 雷 | 死亡与契约的执政面，落在雷的暗心 |
| 空 / 配 | 岩 / 地 | 空间与配位，落在稳定的大地 |
| 生 / 识 | 草 | 生命与意识，落在草的生长 |
| 时 | 风 | 时间与流动，落在风 |

七光在下方排成三环；四影在上方；`01 理` 是接触面。`10 空` 是四影里的“空之执政”，`02 空` 是双子里的“空”，两者不是同一个节点，这是结构里最容易混淆的一点。

双子的两个位置：

- `02 空`：在 `01 理 – 10 配` 的垂直轴上，是“空”的界间位；
- `13 人`：在 4 影与 7 光之间的轨道上，是“人”的界间位。

它们不是第三层，也不是七光之一。双子可以移动、可以挡路，但不能改变 `7+4+2+1` 的计数。

## 七、光锥光学模型

左侧的 Three.js 场景不是装饰，它是一个“三光源 + 一个玻璃锥 + 三圈色散”的光学模型：

- 三个白光光源；
- 三束入射光穿过同一个玻璃锥；
- 在桌面上形成三圈色散；
- 两圈低亮度（死月），一圈高亮度并带紫谱（活月）；
- 中心保持暗。

一个计算上的发现：

```text
朝向中心的 A/B/C 颜色都满足 G > B
加权后的 B/G 大约在 0.27 – 0.80
亮度只能整体放大，不能把 B/G 推过 1
```

所以：

- **中心不可能靠“把三圈调亮”变成紫色**；
- 紫色必须来自额外加入的紫谱，或者来自暗心本身；
- 雷的暗心不是“没调亮”，而是结构上的缺光。

这也是为什么视觉里把紫色放在活环，而把雷留在中心黑处。

## 八、站点结构

站点是一个静态壳，三个视图都在 `index.html` 内切换，不跳页：

| 视图 | URL | 内容 |
|---|---|---|
| Live | `index.html#live` | 左右两个场景并排 |
| 世界式 | `index.html#world` | 右侧 HTML 3D 世界式展开 |
| 光锥 | `index.html#prism` | 左侧 Three.js 光锥展开 |

```text
docs/
  index.html                    站点壳 / 个人站首页
  prism_three.html              Three.js 光锥；?visual=1 为嵌入模式
  world_formula.html            HTML/canvas 3D 世界式；?embed=1 只显示舞台
  world_formula_visual.html     早期静态视觉版（archive）
  world_formula_live_preview.png
  favicon.svg
  .nojekyll
.github/workflows/pages.yml     GitHub Pages 部署
```

- 无 CDN、无外部字体、无追踪脚本。
- Three.js 已经内联进 `prism_three.html`。
- 两个 iframe 必须和 `index.html` 放在同一个 `docs/` 目录。
- 页面内可拖拽旋转、滚轮缩放；主导航不离开站点壳。

### 展示版与理想解

三环理想解把岩放在 `r = 3.5` 的位置，这样三个环严格等圆。  
当前 3D 世界式为了构图，把 `09 岩` 放在约 `r = 3.9` 的位置，和理想解差 `0.4`。

这只影响画面，不改变 `7+4+2+1` 的拓扑和计数；但如果你要严格的“三圆同半径”，应以 `3.5` 为准。

## 十一、边界

这套结构能给出约束，但不能替代官方设定：

- 哪些是几何事实：三环半径、六个交点、雷在中心、`14 = 7+4+2+1` 的计数；
- 哪些是叙事推测：四影与元素的对应、雷眼停发的机制、反主与界面的关系；
- 哪些是可证伪的：
  - 如果雷眼还在中心全黑时继续发放，说明雷眼并不依赖中心；
  - 如果反主被确认坐在雷位，说明“人和元素分离”不成立；
  - 如果雷神重新发放雷眼而中心不变，说明“中心闭合”不是充分条件。

结构不是 canon。  
它只是把“为什么偏偏是雷”“为什么紫在活环”“为什么反主只能卡界面”这些问题，放进同一张能自洽的图里。
