# 三月 · 三域

> 两死，一生。日、月、星三圆交叠；七元素各坐一个交叉焦点，雷在正中。

**线上站：[kenneykun.github.io/genshin347puzzle](https://kenneykun.github.io/genshin347puzzle/)**

把提瓦特的 **3 / 4 / 7** 放进同一个可旋转的几何结构里的视觉笔记：

- **3** —— 三条域圆：**日 / 月 / 星**
- **4** —— 四块交叠区，读作 **四影**：生 / 空 / 死 / 时
- **7** —— 七个元素座位，坐在六个**交叉焦点**与正中央

```text
3 + 4 + 7 = 14
```

![站点预览](docs/world_formula_live_preview.png)

## 这版在做什么

左侧是一台可以转的几何装置（Three.js），右侧是同一套几何的节点化读法（纯 Canvas / DOM，无依赖）。

- 三条圆 = 日 / 月 / 星三域，每条圆扫过一整圈色相，交叉处加法叠加出第三种颜色；
- 七个元素坐在**圆与圆的交叉焦点**上，六个焦点围成六边形，雷在正中；
- 三条圆两两交叠加中央三重交叠，正好**四块透镜区**，对应四族反应，读作四影；
- 「两死一生」落在三域的亮度上：三域里只有一域活着，其余压暗（默认月域，可切换）。

这一版把**结构**当作主干，光学退成脚注（见〈已归档：光栅那一版〉）。

## 几何

三个等边三角形的嵌套给出全部坐标：

```text
外三角半径 R = 7
内三角半径 r = 3.5
圆半径     ρ = √(R² − Rr + r²) = √36.75 ≈ 6.0622

恒等式：ρ = r√3 = 内三角边长
```

所以**每个圆的圆心都落在另外两个圆上**——这是整个图能闭合的原因，也是六个焦点存在的理由。

| 域 | 圆心 (x, z) | 圆心方位角 |
|---|---|---:|
| 日 | (0, 3.5) | 90° |
| 月 | (−3.03, −1.75) | 210° |
| 星 | (3.03, −1.75) | 330° |

六个交叉焦点每隔 60° 一个，且**交替落在内圈与外圈**：三个在 r = 3.5（正好是两个月亮的圆心），三个在 R = 7（外三角）。

## 七座：元素坐在焦点上

从正上方顺时针：

| 元素 | 位置 | 半径 | 在哪些圆上 |
|---|---|---:|---|
| 火 | (0, 3.5) | 3.5 | 日、月 |
| 风 | (6.06, 3.5) | 7 | 日、月 |
| 冰 | (3.03, −1.75) | 3.5 | 日、星 |
| 岩 | (0, −7) | 7 | 月、星 |
| 水 | (−3.03, −1.75) | 3.5 | 日、月 |
| 草 | (−6.06, 3.5) | 7 | 日、星 |
| **雷** | (0, 0) | 0 | **三元交叠（中心）** |

每条圆正好压着四个座位，于是每条圆可以用这四个座位的元素色做色锚：环上是一圈连续光谱，座位附近被拉回该元素的色调。

> **雷在中心**的理由是设定而非推导：永恒最接近天理，而雷神坚守永恒。天理（点光源）压在中央轴线的正上方，雷是所有座位里离它最近的那个。

## 四影：元素在哪里相遇

| 交叠区 | 影 | 该区的反应族 |
|---|---|---|
| 日 ∩ 月 | **生** | 燃烧 · 绽放 |
| 日 ∩ 星 | **空** | 扩散 |
| 日 ∩ 月 ∩ 星（中央） | **死** | 超载 · 感电 · 超导 |
| 月 ∩ 星 | **时** | 结晶 |

「四影 = 四块交叠区」是这张图的读法，不是官方设定；它的好处是让 14 这个数在几何里有了第二处落点：

```text
三条域圆（3） + 四块交叠（4） + 七个座位（7） = 14
```

## 两死一生

三域里只有一域还在推进，另外两域定格：

- 默认**月域**活着：环更亮、更饱和，域标签更大；
- 侧栏「活域」可切换日 / 月 / 星，切换后亮度与标签立即重排；
- 地址栏 `?alive=sun` / `?alive=moon` / `?alive=star` 可直接指定。

```text
两死，一生 → 三域里只有一域还在亮
```

### 右侧：世界式十四节点图（`docs/world_formula.html`）

同一套几何，换成节点化的读法：

- 三条域圆与左侧同心同半径；
- 七元素落在同样的六个焦点 + 中央；
- 四影挂在四块交叠区上方；
- 其余节点（天理、双子、界间）保持原来的层级关系。

地址栏 `?still=1` 关闭自转，`?embed=1` 进入嵌入模式。

## 已归档：光栅那一版

在切到三域结构之前，这个项目做过一版严格光学的模型，用光栅方程解释六焦点与颜色：

- 三环 = 三月各自凹面光栅的**罗兰圆**（R = 2ρ，圆半径正好是 ρ）；
- 光栅方程 `d(sinα + sinβ) = mλ`，取 `d = 500 nm`、`α = 30°`、`m = +1`，可见光只占 **46.7°** 的弧；
- 数值校验证明：七色无法稳定落在六个焦点上——5040 种排列没有一种能让三条环同时单调，且三条环的光栅间距需要 430 / 355 / 430 nm（21% 偏差）。

结论是「六个交点 = 元素座位」无法由光栅单独推出，所以那一版把颜色交给光谱、把座位让空。这一版换了主次：**座位是主干的读法，光学不再是立法者**。

代码没有删干净：左侧「已退役控件」折叠区里仍能调出光栅转角、闪耀窗口与旧色带参数，用于对照。历史见 git log。

## 边界

- **这是模型，不是考据。** 三域、四影挂区、元素座位都是把已有设定整理进几何的读法；官方设定没有这么写。
- **哪些是可算的**：三圆坐标、六焦点位置、`ρ = r√3` 的恒等式、色板与 ΔE、每条圆压着哪四个座位——这些都可以验算。
- **哪些是选择**：谁坐哪个焦点、四影如何对应四块交叠、哪一域活着——这些是设计选择，改了不算错，只是另一种读法。
- **不宣称**：不宣称这是唯一解，也不宣称它是官方隐藏结构。
