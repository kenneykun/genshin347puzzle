# 三月 · 三域

> 两死，一生。日、月、星三圆交叠；六元素坐在交叉焦点上，雷不占座位——它是盘面本身。

**线上站：[kenneykun.github.io/genshin347puzzle](https://kenneykun.github.io/genshin347puzzle/)**

把提瓦特的 **3 / 4 / 7** 放进同一个可旋转的几何结构里的视觉笔记：

- **3** —— 三条域圆：**日 / 月 / 星**
- **4** —— 四块交叠区，读作 **四影**：生 / 空 / 死 / 时
- **7** —— 七个元素：六个坐在**交叉焦点**上，雷不占座位，它是盘面本身

```text
3 + 4 + 7 = 14
```

![站点预览](docs/world_formula_live_preview.png)



## 几何

三个等边三角形的嵌套给出全部坐标：

```text
外三角半径 R = 7
内三角半径 r = 3.5
圆半径     ρ = √(R² − Rr + r²) = √36.75 ≈ 6.0622

恒等式：ρ = r√3 = 内三角边长
```

所以**每个圆的圆心都落在另外两个圆上**——这是整个图能闭合的原因，也是六个焦点存在的理由。

| 域 | 圆心 (x, z) | 圆心方位角 |
|---|---|---:|
| 日 | (0, 3.5) | 90° |
| 月 | (−3.03, −1.75) | 210° |
| 星 | (3.03, −1.75) | 330° |

六个交叉焦点每隔 60° 一个，且**交替落在内圈与外圈**：三个在 r = 3.5（正好是两个月亮的圆心），三个在 R = 7（外三角）。

## 座位：元素坐在焦点上，雷是盘面

从正上方顺时针：

| 元素 | 位置 | 半径 | 在哪些圆上 |
|---|---|---:|---|
| 火 | (0, 3.5) | 3.5 | 日、月 |
| 风 | (6.06, 3.5) | 7 | 日、月 |
| 冰 | (3.03, −1.75) | 3.5 | 日、星 |
| 岩 | (0, −7) | 7 | 月、星 |
| 水 | (−3.03, −1.75) | 3.5 | 日、月 |
| 草 | (−6.06, 3.5) | 7 | 日、星 |
| 雷 | — | — | **不占座位：它是盘面本身** |

每条圆正好压着四个座位，于是每条圆可以用这四个座位的元素色做色锚：环上是一圈连续光谱，座位附近被拉回该元素的色调。

> **雷不占座位**：它能和任何元素反应，所以在图上它不是第七个点，而是**整块盘面的性质**——底盘是一张始终带电的雷电盘，静电弧在盘面上随机闪现、电荷粒子在盘面之上漂浮。永恒最接近天理，而雷神坚守永恒；这条设定解释了为什么雷是"介质"而不是"座位"。

## 四影：元素在哪里相遇

| 交叠区 | 影 | 该区的反应族 |
|---|---|---|
| 日 ∩ 月 | **生** | 燃烧 · 绽放 |
| 日 ∩ 星 | **空** | 扩散 |
| 日 ∩ 月 ∩ 星（中央区） | **死** | 超载 · 感电 · 超导 |
| 月 ∩ 星 | **时** | 结晶 |

「四影 = 四块交叠区」是这张图的读法，不是官方设定；它的好处是让 14 这个数在几何里有了第二处落点：

```text
三条域圆（3） + 四块交叠（4） + 七个座位（7） = 14
```

## 两死一生

三域里只有一域还在推进，另外两域定格：

- 默认**月域**活着：环更亮、更饱和，域标签更大；
- 侧栏「活域」可切换日 / 月 / 星，切换后亮度与标签立即重排；
- 地址栏 `?alive=sun` / `?alive=moon` / `?alive=star` 可直接指定。

```text
两死，一生 → 三域里只有一域还在亮
```

## 抖音成片（v1.0.0 封版）

`video/` 是把上图的读法做成 **9 镜竖屏视频**的完整管线（1080×1920 / 30fps / 约 78 秒 / 纯人声音轨 + 抖音式逐句大字幕）：

| 阶段 | 做什么 | 入口 |
|---|---|---|
| 版式 | 单文件 HTML 画每一镜（含 3D 底片叠加层、透明字幕层） | `video/slides.tpl.html` |
| 采样 | CDP 抓站点 3D 底片与透明图层 | `video/capture_clips.mjs` / `video/capture_wf.mjs` |
| 配音 | 中文女声 + 广播级后处理（可选本地 MeloTTS） | `video/tts.py` / `video/voice_lab.py` |
| 合成 | 逐帧合成 + ffmpeg 编码 + 抖动 | `video/render.py` |
| 交付 | 封面 / 分镜 PDF / 发布配置 | `video/deliver.py` |

一键：`pwsh video/build.ps1`。

- 逐镜脚本、旁白、时长、风险表：`plan/douyin_video_plan.md`
- 发布配置（标题 / 话题 / 简介 / 自查清单）：`video/out/publish.md`
- 逐句字幕时间轴：`video/out/subtitles.srt`

**不入库的产物**：`video/build/`（抓帧与中间层，数百 MB）、成片 MP4、封面、分镜 PDF、试听样音、`video/assets/`（站点截图与官方元素图标）。
元素图标取自游戏内卡牌 UI，属米哈游素材的同人使用，因此仓库只保留抓取脚本 `video/fetch_element_icons.py`，不转存原图。
