# 三月 · 世界式

> 两死，一生。月光静止，雷色不现。

**线上站：[kenneykun.github.io/genshin347puzzle](https://kenneykun.github.io/genshin347puzzle/)**

这里用“三月”而不是“三光”：三月亮本身不发光，我们看到的是它们反射的月光。

这是一套从三环几何、十四席计数和雷神之眼停发现象反推的视觉猜想。不是官方设定。

![站点预览](docs/world_formula_live_preview.png)

## 公式

```text
7 光 + 4 影 + 2 界间 + 1 天理 = 14
7 + 4 = 11
11 + 1 + 2 = 14
```

- **7 光**：冰、水、火、草、风、岩、雷。
- **4 影**：死、生、时、空。
- **2 界间**：`02 空`、`13 人`。双子不是一层。
- **1 天理**：`01 理`。它在光与影之间，不在影的后面。

这套十四席也用来对照《崩坏》侧的十四位律者；逐席对应是解释性的，不是官方名单。

四影在上，七光在下，天理在接触面。双子横跨界面：`02 空` 在 `01 理 – 10 配` 的轴线上，`13 人` 在四影与七光之间的轨道上。

## 核心猜想

1. **14 不是 7+7，而是 7+4+2+1。** 七元素、四影、双子和天理分属不同层级。
2. **七元素由六个两两交点加一个中心组成。** 冰、水、火、草、风、岩在六个两两交点上；雷在三环中心，是三重叠加，不是第七个两两交点。
3. **雷眼停发更可能来自“光谱静止”，而不是中心闭合。** 两个死月把两个环固定；活月的光谱也静止；三环中心的混色固定，雷的颜色无法出现。
4. **紫不是深渊本身，是深渊的侵蚀。** 紫色在活着的环上；它把活月的光谱钉住，三环混色不再变化。
5. **反主不能坐雷位。** 他只能占 `02 空` 或 `13 人` 的界间位，卡住光路、遮住界面，但不能把自己变成雷。
6. **天理在光与影之间。** 不是把天理放到影的背后，而是让 `01` 成为四影与七光的接触面。
7. **中心不能靠叠亮变紫。** 三个环朝向中心的颜色都是 G>B；亮度不能把 B/G 推过 1。中心是固定的混色，不是灯。

## 三环解

```text
外三角半径 R = 7
内三角半径 r = 3.5
环半径 ρ = √(R² − Rr + r²)
         = √36.75
         ≈ 6.0622
```

三个环心落在内三角节点上：

- A：风 `(3.03, −1.75)`
- B：岩 `(0, 3.5)`
- C：草 `(−3.03, −1.75)`

六个两两交点：

```text
A ∩ B：冰、草
B ∩ C：水、风
C ∩ A：火、岩
```

草、风、岩同时是另一个环的圆心；六个点都是两两交点。

**雷是第七个点，但不是第七个两两交点。** 它在三环中心，是三条环带的三重叠加。只有把中心也当作“三重交点”，雷色才有出现的位置。

颜色角度（世界坐标，从 x 轴逆时针）：

```text
冰：A60 / B0        水：B180 / C120
火：A240 / C300     草：A180 / B240
风：B300 / C0       岩：A120 / C60
雷：中心三重叠加
```

每个两两交点上的两个环必须同色。环 C 是活着的月亮，额外加入紫谱；水仍在 120° 保持水蓝。

> 展示版为了构图，把 `09 岩` 放在约 `r = 3.9`；严格三环解是 `r = 3.5`，差 0.4，但拓扑不变。

## 雷眼为什么停发：光谱静止假说

### 三个环的状态

- 两个死月：两个环的光谱固定；
- 活月：如果它的光谱也静止，第三个环同样固定；
- 三环中心：三个固定光谱叠加，混色固定。

在这种状态下，六个两两交点的颜色不会变，中心的三重叠加也不会产生新的雷色。新的雷神之眼自然不出现。

关键在于：**两个死月只能固定两个环。** 如果活月仍在运动，中心混色仍会变化；所以“活月也静止”是必要条件。

### 为什么不是“中心闭合”

“中心闭合”需要额外假设一个盖子。  
“光谱静止”不需要：它只要求三环的光谱不再变化，中心自然是同一个混色。

因此更简约的因果是：

```text
死月固定 + 活月静止
        → 三环混色固定
        → 雷色不出现
        → 雷眼停发
```

“中心黑”不是原因，而是这个固定混色的结果。

### 与其他读法的区别

| 读法 | 结构判断 |
|---|---|
| 中心闭合 | 较弱；需要额外假设，光谱静止已足够 |
| 被深渊遮蔽 | 不准确；深渊在暗心内侧，不是外侧幕布 |
| 雷位被反主占据 | 不成立；人和元素是两类节点 |
| 光谱静止 | 更自洽；只依赖三环状态 |

### 空月之歌的预测

如果《空月之歌》结束、月亮回归、活月的光谱重新流动，那么三环中心的混色会重新变化，雷色可能再次出现，雷眼也可能恢复发放。

这是一个可证伪的预测：

- 如果三月亮仍静止，雷眼却恢复 → 光谱静止说失败；
- 如果月亮回归，雷眼仍不恢复 → 还需要别的条件；
- 如果雷眼恢复而中心混色没有出现雷色 → “雷色来自中心”也不成立。

## 紫与暗心

- 紫在活环上；
- 雷心是固定混色；
- 紫越重，说明活月被深渊钉得越死；
- 但紫色不是雷，中心也不是被紫色覆盖。

所以页面文案用：

```text
紫 = 深渊之蚀
雷眼 = 未现之色
月光静止，雷色不现
```

“雷眼”不是闭上的瞳孔，而是三环中心没有生成的那个颜色。

## 反主与界面

`13 人` 在四影与七光之间的轨道上；`02 空` 在 `01 理 – 10 配` 的轴线上。

- 占 `13 人`：可以挡光；
- 占 `02 空`：可以堵住中心通道；
- 占雷位：会让人和光重复计数，`7+4+2+1=14` 就破了。

反主能做的是关闸、遮光、卡界面，不是变成雷。

## 四影与双子

| 四影 | 对应元素 | 读法 |
|---|---|---|
| 死 / 约 | 雷 | 死亡与契约，落在雷的暗心 |
| 空 / 配 | 岩 / 地 | 空间与配位，落在稳定的大地 |
| 生 / 识 | 草 | 生命与意识，落在草的生长 |
| 时 | 风 | 时间与流动，落在风 |

`10 空` 是四影里的空之执政；`02 空` 是双子里的空。两者不是同一个节点。

双子不是第三层，也不是七光之一。它们可以移动、可以挡路，但不能改变 `7+4+2+1` 的计数。

## 光锥与紫色

左侧 Three.js 场景是“三束月光 + 玻璃锥 + 三圈色散”。渲染时用三个光源代替反射的月光，不是三颗自己发光的星。

- 两圈低亮度：死月；
- 一圈高亮度并带紫谱：活月；
- 中心保持暗。

一个计算上的发现：

```text
朝向中心的 A/B/C 颜色都满足 G > B
加权后的 B/G 大约在 0.27 – 0.80
亮度只能整体放大，不能把 B/G 推过 1
```

所以中心不能靠“把三圈调亮”变成紫色；紫色必须来自额外紫谱，或者来自暗心的固定混色。

## 尚待验证

这套模型仍需要对《空月之歌》的三月模型进行进一步验证。

需要特别核对：

- 两个死月的光谱是否真的固定；
- 活月是否真的完全静止，还是只是相位/位置暂时不变；
- 《空月之歌》结束后，月亮回归是否会让三环混色重新变化；
- 雷神之眼恢复发放时，中心是否真的出现新的雷色。

在这些问题有答案之前，“光谱静止”只是目前更简约的解释，不是定论。

## 边界

- 几何事实：三环半径、六个两两交点、雷在三环中心、`7+4+2+1=14` 的计数。
- 叙事推测：四影与元素的对应、雷眼停发的机制、反主与界面的关系。
- 可证伪：见上面的“空月之歌的预测”。

结构不是 canon。它只是把“为什么偏偏是雷”“为什么紫在活环”“为什么月亮回归可能让雷眼恢复”放进同一张能自洽的图里。
