# 三月 · 世界式

> 两死，一生。月光静止，雷色不现。

**线上站：[kenneykun.github.io/genshin347puzzle](https://kenneykun.github.io/genshin347puzzle/)**

这里用“三月”而不是“三光”：三月亮本身不发光，我们看到的是它们反射的月光。

这是一套从三环几何、十四席计数和雷神之眼停发现象反推的视觉猜想。不是官方设定。

![站点预览](docs/world_formula_live_preview.png)

## 公式

```text
7 光 + 4 影 + 2 界间 + 1 天理 = 14
7 + 4 = 11
11 + 1 + 2 = 14
```

这里的 **7 光**不是七个固定节点，而是：

```text
6 个固定交点 + 1 个移动的雷色
```

- **6 个固定交点**：冰、水、火、草、风、岩。
- **1 个移动的雷色**：雷。它不再固定在三环中心，而是在活月的光谱上流动；扫到哪个交点，哪个交点才暂时成为雷。
- **4 影**：死、生、时、空。
- **2 界间**：`02 空`、`13 人`。双子不是一层。
- **1 天理**：`01 理`。它在光与影之间。

这套十四席也用来对照《崩坏》侧的十四位律者；逐席对应是解释性的，不是官方名单。

## 核心猜想

1. **14 不是 7+7，而是 7+4+2+1。** 七光、四影、双子和天理分属不同层级。
2. **六个固定交点归六元素；雷不是第七个固定点。** 三环中心现在是空的，不再是雷的座位。
3. **雷是一条移动的紫色谱带。** 它沿活月环流动；不碰交点时，雷不出现；碰到哪个交点，哪个交点才暂时成为雷。
4. **静止 = 雷色不现。** 两个死月固定两环，活月的紫色谱带也静止；只要它停在两个交点之间，就没有雷。
5. **紫是雷色，不是深渊本体。** 深渊/槲寄生是“把紫色谱带钉住”的原因；紫色本身是雷色。
6. **反主不能坐雷位。** 雷已经没有固定座位；反主只能占 `02 空 / 13 人` 的界间位，卡住光路。
7. **天理在光与影之间。** 不是把天理放到影的背后，而是让 `01` 成为四影与七光的接触面。

## 三环解

```text
外三角半径 R = 7
内三角半径 r = 3.5
环半径 ρ = √(R² − Rr + r²)
         = √36.75
         ≈ 6.0622
```

三个环心：

- A：风 `(3.03, −1.75)`
- B：岩 `(0, 3.5)`
- C：草 `(−3.03, −1.75)`

六个两两交点：

```text
A ∩ B：冰、草
B ∩ C：水、风
C ∩ A：火、岩
```

六个点都是固定节点；**三环中心没有第七个节点**。

颜色角度（世界坐标，从 x 轴逆时针）：

```text
冰：A60 / B0        水：B180 / C120
火：A240 / C300     草：A180 / B240
风：B300 / C0       岩：A120 / C60
雷：没有固定角度；在 C 环上流动
```

每个固定交点上的两个环必须同色。  
雷是唯一例外：它是移动色，可以暂时覆盖一个交点，不需要另一条环也变成紫色。

## 静止与流动：关键计算

旧版的 C 环有三段静止紫谱：

```text
180°–240°
240°–300°
330°–360°
```

C 的交点是：

```text
风 0° / 岩 60° / 水 120° / 火 300°
```

静止时，紫色段在 0° 和 300° 刚好收尾，端点上取元素色，所以没有紫色进入交点。  
但这个静止相位是刀刃：

```text
+1°：风、火同时进入紫色段
-90°：水进入紫色段
完整旋转：每个 C 交点都会被紫色扫过
```

所以“流动必然经过交点”成立；也说明旧版三段紫谱很难保证一次只出现一个雷。

新版改成 **单条 24° 紫色谱带**：

- 24° < 交点间距 60°，任何时刻最多覆盖一个 C 交点；
- 初始停在 270°，位于 300° 与 0° 之间，不碰任何交点；
- 谱带开始流动后，依次扫过 300°、0°、60°、120°；
- 扫到哪个交点，哪个交点暂时点亮“雷”。

这就把“雷”从固定中心改成一个 **移动色事件**，同时避免多个交点同时变成雷。

## 雷神之眼为什么停发

```text
两个死月 → A/B 两环固定
活月被槲寄生钉住 → C 环的紫带静止
紫带停在交点之间 → 没有交点被雷色覆盖
→ 雷色不现
→ 雷神之眼停发
```

这里不再需要“中心闭合”。  
中心空着；雷的缺失不是中心黑了，而是 **紫色谱带没有经过任何交点**。

### 槲寄生实验的硬约束

如果“冰之女皇用槲寄生对少女（月神）做实验”的剧情成立，它必须是：

> **寄生 / 冻结 / 维持，不能是杀死。**

如果少女/月神被杀死，C 环也应该死，画面就变成“三死”，不是“两死一生”。  
槲寄生是寄生植物，不立刻杀死宿主，正好对应“活月还亮着，但紫带不再流动”。

冰之女皇的动机可以有两种读法：

- **控制**：把最后一个活月变成可控制的固定光源；
- **保存**：用寄生维持最后一个活月，代价是它不再运动。

结构只判定“必须冻结”，不判定动机。

### 空月之歌的预测

如果《空月之歌》结束、月亮回归、紫带重新流动：

- 谱带会再次扫过交点；
- 雷色会重新出现；
- 雷神之眼可能恢复发放。

可证伪：

- 月亮仍静止，雷眼却恢复 → 静止说失败；
- 月亮回归，雷眼仍不恢复 → 还需要别的条件；
- 紫带扫过交点，但没有出现雷 → “交点雷色”说失败。

## 四影与双子

| 四影 | 对应元素 | 读法 |
|---|---|---|
| 死 / 约 | 雷 | 死亡与契约，对应移动的雷色 |
| 空 / 配 | 岩 / 地 | 空间与配位，落在稳定的大地 |
| 生 / 识 | 草 | 生命与意识，落在草的生长 |
| 时 | 风 | 时间与流动，落在风 |

`10 空` 是四影里的空之执政；`02 空` 是双子里的空。两者不是同一个节点。

双子不是第三层，也不是七光之一。它们可以移动、可以挡路，但不能改变 `7+4+2+1` 的计数。

## 光锥与紫色

左侧 Three.js 场景现在是：

- 两个死月环：A/B 固定；
- 活月环 C：只有一条 24° 紫色谱带在流动；
- 谱带不碰交点时，没有雷；
- 谱带经过交点时，该交点白圈变紫，并出现“雷”标记；
- 三环中心保持空，不再有雷的固定标记。

渲染时用三个光源代替反射的月光，不是三颗自己发光的星。  
紫带是雷色；深渊/槲寄生是让它停住的原因，不是紫带本身。

## 尚待验证

这套模型仍需要对《空月之歌》的三月模型进行进一步验证。

需要特别核对：

- 两个死月的光谱是否真的固定；
- 活月的紫带是否真的被槲寄生钉住，而不是相位暂时不变；
- 紫带扫过交点时，是否真的只有一个交点成为雷；
- 空月之歌结束后，月亮回归是否会让雷色恢复。

在这些问题有答案之前，“移动雷色 + 光谱静止”只是目前更简约的解释，不是定论。

## 边界

- 几何事实：三环半径、六个两两交点、`7+4+2+1=14` 的计数。
- 结构选择：雷从中心节点改成移动色，是本模型为了解释“静止不现、流动出现”做的重定义。
- 叙事推测：四影与元素的对应、雷眼停发的机制、槲寄生实验、反主与界面的关系。

结构不是 canon。它只是把“为什么偏偏是雷”“为什么静止不现”“为什么紫带经过交点才出现雷”放进同一张能自洽的图里。
